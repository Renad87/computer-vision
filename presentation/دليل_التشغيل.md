# دليل تشغيل نسخة الديوان

## التشغيل

1. افتح `presentation/diwan_edition/Poetry_Vision_Diwan.html` في Google Chrome.
   - الملف واحد ومستقل (≈ ٣٫٢ ميغابايت)، ويعمل دون إنترنت.
   - الخطوط Amiri وIBM Plex Sans Arabic وInter مضمّنة فيه.
   - خط Aref Ruqaa للعناوين مضمّن أيضًا (رخصة OFL 1.1).
2. اضغط «ملء الشاشة» أو المفتاح F.
3. اختر أحد الزرين:
   - **ابدأ العرض:** دخول سينمائي إلى الغرفة، نحو ٢٥ ثانية، ويمكن تخطيه بزر «تخطّي المشهد» أو المفتاح S.
   - **الانتقال مباشرة إلى الديوان:** يبدأ مباشرة عند المكتب.
4. عندما يظهر «اضغط على الديوان»، اضغط عليه أو اضغط Enter لفتح الكتاب.

## التنقل

| المفتاح | الوظيفة |
|---|---|
| ← أو المسافة أو PgDn، أو الضغط على الحافة اليسرى للكتاب | الصفحة المزدوجة التالية. الضغط أثناء الكتابة التدريجية يُكملها فورًا، وضغطة ثانية تقلّب الصفحة. |
| → أو PgUp | السابقة |
| رقم ثم Enter | الانتقال إلى الصفحة المزدوجة ١–١٤ |
| T أو Home، أو الضغط على شريط الكتاب | الفهرس |
| R | إعادة تشغيل حركة الصفحة الحالية |
| A أو زر «الملحق» | الملحق العلمي (١٤ قسمًا). Esc للعودة. |
| N أو زر «الملاحظات» | نص الإلقاء للصفحة الحالية أسفل الشاشة |
| L (في الصفحة ١٣) | فتح الموقع الحقيقي `http://127.0.0.1:8010` |
| H (في الصفحة ١٣) | اللقطات الاحتياطية الحقيقية |
| زر «المؤثرات» | تشغيل أصوات الورق والخطوات أو إيقافها |
| ختم «إنهاء العرض» (الصفحة الأخيرة) | الخروج السينمائي من الغرفة (نحو ١٨ ثانية). يمكن تخطيه بالمفتاح S. |

**الصوت:**
- حُذفت الموسيقى بناءً على طلب صاحب المشروع.
- بقيت مؤثرات خافتة فقط (الخطوات والباب والورق والفنجان)، ويمكن إيقافها بزر «المؤثرات».
- العرض يعمل كاملًا دون صوت.

## التجربة الحية

1. قبل العرض، شغّل الموقع من جذر المشروع:
   ```bash
   ./run.sh
   ```
   انتظر سطر READY.
2. في الصفحة ١٣ اضغط «افتح الموقع الحقيقي» أو المفتاح L.
3. ارفع اللوحة نفسها: `presentation/final/protagonist/protagonist_2400.png`.
4. إن تعطّل الموقع، اضغط «اللقطات الاحتياطية» أو المفتاح H.

## إعادة البناء

يُعاد البناء عند تغيّر النتائج أو المحتوى، بالأمر:

```bash
python3 presentation/diwan_edition/build_diwan.py
```

- الملف الأصلي لزميلتنا محفوظ دون تعديل في `diwan_edition/original/`، وبصمته SHA-256 تُفحص عند كل بناء.
- كل تعديل على ملفها استبدال نصي موثّق في `build_diwan.py`.

# Poetry Vision — المواصفة المعتمدة v1

- **الحالة:** اعتمد المالك بدء M0–M1 في 2026-11-25. المرجع: التسليم التخطيطي النهائي المتفق عليه بين Claude وChatGPT.
- **الموعد:** الخميس 26 نوفمبر 2026. ساعة التسليم لم تُحدد بعد (قرار للمالك).

## الهدف

صورة RGB واحدة تمر بنموذج CV واحد في مرور واحد، فيخرج:
- مشهدًا: 16 فئة + `other`؛
- إحساسًا تثيره الصورة: 8 فئات EmoSet؛
- وسومًا بصرية: 13 وسمًا متحققًا منه.

ثم يؤكد المستخدم المشهد أو البؤرة، ويختار إحساسًا أدبيًا. بعدها يعيد المحرك حتى 3 أبيات أصيلة من مدونة مراجَعة بشريًا، مع تفسير حتمي، أو يمتنع مع سبب معلن.

## المعمارية

```
BUILD TIME (offline)
  EmoSet sample ───┐
  Places365 sample ┼─► manifest_v1.jsonl [Shaden]  approach D: original labels
  PV-Test (frozen) ┘     + audited EmoSet scene attribute + masks + quarantine
  CLIP ViT-B/32 (frozen) ─► features cache ─► heads + temperatures [Omar]
  APCD ─► discover.py [Mohammed] ─► annotate / review / adjudicate ─► pilot_v1.jsonl [Omar]

RUN TIME (one model, one forward pass; no LLM, no RAG, no YOLO)
  photo ─► exif_transpose ─► open_clip preprocess ─► CLIP visual ─► z (512, L2)
     z ─► scene   512→17 ─/T─► 16 scenes + other ─► 9 scene groups ──┐
     z ─► emotion 512→8  ─/T─► 8 image emotions ─► mapped suggestions ├─► inference_output
     z ─► tags    512→34 ─► per-tag thresholds ─► 13 validated tags ──┘
  UI ─► image_profile ─► retrieval: E gate ─► tier by reviewed relation ─► Score ─► ≤3 verses | abstain
```

## قواعد الاسترجاع المتفق عليها

- **الأهلية:** الإحساس الأدبي المختار يجب أن يكون موسومًا ومراجَعًا في البيت.
  - E = 1.0 إن كان أساسيًا، و0.6 إن كان ثانويًا؛ وإلا فالبيت غير مؤهل.
  - البيت المحايد أو الملتبس أو غير المعلَّق غير مؤهل، ولا يُعد ذلك تعارضًا.
- **V:** تغطية موزونة على العناصر البصرية المؤكدة. الأوزان: البؤرة 2، والأساسي 1، والثانوي 0.5.
  - ρ: literal 1.0، scene_association 0.7، symbolic 0.4 (فقط إن سُمح بالرمزي)، negated/hypothetical/ambiguous 0.
- **المستويات:**
  - Tier 1: علاقة literal أو scene_association مع البؤرة إن وُجدت، وإلا مع أي عنصر مؤكد.
  - Tier 2: علاقة symbolic مراجَعة، والرمزي مسموح.
  - Tier 3: الإحساس وحده، فقط إن سمح المستخدم، وبيت واحد كحد أقصى.
  - التشابه النصي وحده لا يُثبت علاقة بصرية.
- **الدرجة:** `Score = 0.45E + 0.35V + 0.20T`. T جيب تمام TF-IDF smoothed غير سالب. القيم null تُحذف ويُعاد تطبيع الأوزان. لا min-max.
- **الحالات الأخرى:** امتناع معلَّل؛ لا رجوع إلى مدونة غير مراجَعة؛ تفسيرات بقوالب ثابتة من حقول مراجَعة.

## النسخة الدنيا مقابل الهدف

- **الدنيا (عند الموعد):**
  - Stage 1؛
  - P0 من 50–60 بيتًا (أو ما تبرره الإنتاجية المقيسة)؛
  - B1 وB4 وB5؛
  - PV-Test من 30–40 صورة؛
  - تقييم مصغّر بالطبقات الأربع؛
  - النظام القديم احتياطًا.
- **الهدف (بعد الموعد):**
  - Stage 2، وStage 3 إن ثبتت جدواه؛
  - نحو 1,000 بيت على مراحل P1–P3؛
  - Word2Vec؛
  - PV-Test من 100 صورة فأكثر؛
  - مقيّمون خارجيون.

## البوابات (H ساعة التسليم، T0 لحظة الموافقة)

| البوابة | التوقيت | الشرط |
|---|---|---|
| G0 | T0 + 2 ساعة | حالة الأصول معروفة |
| G1 | H − 10 | Stage 1 مقبول (A1–A3)، وإلا قرار الاحتياط |
| G2 | H − 6 | smoke التكامل ناجح، وP0 مجمّد |
| G3 | H − 3 | الكود مجمّد، والتقييم جارٍ |
| G4 | H − 1 | الشرائح والتمرين، وقرار العرض |

- **ترتيب القطع إن كانت `H − T0` أقل من 16 ساعة:**
  1. Stage 2؛
  2. Word2Vec وBGE-M3؛
  3. N2؛
  4. P0 إلى 30–40 بيتًا؛
  5. PV-Test إلى 20 صورة؛
  6. رابط التاريخ.
- **لا يُقطع أبدًا:**
  - أصالة النص، وحالات المراجعة؛
  - العقود والـvalidators؛
  - الاختبار المجمّد؛
  - النموذج الواحد؛
  - الإبلاغ الأمين.
